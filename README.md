# Vision Project

البرنامج بيشتغل على الكاميرا أو على فيديو، وبيعمل الحاجات دي:

1. **عدّ الأشخاص** في بانل جانبية: الموجودين دلوقتي، وإجمالي اللي ظهروا، ومعاهم الـ FPS
2. **الوش بالتفاصيل:** 106 نقطة على الوش، والنوع (Male / Female)
3. **الشنط وحجمها:** شنطة ضهر، إيد، سفر، صغيرة أو متوسطة أو كبيرة، مع تقدير تقريبي بالسنتيمتر. بيستخدم موديل متدرب مخصوص للشنط (`models/bags_best.pt`)
4. **لو الشخص ماسك حاجة في إيده** (HELD): بيستخدم 21 نقطة لكل إيد من MediaPipe Hands عشان يشوف الصوابع
5. **كل الحاجات اللي في الصورة:** بيتعرف عليها ويعدها، حتى لو مفيش ناس في الكادر
6. **التسجيل:** بيحفظ الفيديو بالرسومات، وملفات CSV، وصور الوش والشنط في فولدر `results`

## الملفات

| الملف | وظيفته |
|---|---|
| `vision_pipeline.py` | البرنامج الأساسي |
| `setup.ps1` | بيسطب كل حاجة: Python وvenv وPyTorch GPU والمكتبات وonnxruntime GPU |

## التشغيل

- دبل كليك على `run.bat` (هيفتح كاميرا 0)
- أو من الـ terminal:
  ```powershell
  .\run.bat            # الكاميرا
  .\run.bat video.mp4  # فيديو
  ```
- عشان تقفل اضغط `q` وانت واقف على شباك الفيديو. لازم تقفل بـ `q` عشان الفيديو والملفات يتحفظوا صح
- من غير حفظ فيديو: `venv\Scripts\python vision_pipeline.py --source 0 --no-video`
- من غير CSV: ضيف `--no-log`

## ملفات النتايج

كل تشغيلة بتعمل فولدر جديد جوه `results\` باسم التاريخ والوقت، وفيه:

| الملف | فيه إيه |
|---|---|
| `video.mp4` | الفيديو بكل الرسومات والبانل |
| `events.csv` | كل حدث بوقته: `enter`، `exit`، `start_holding`، `stop_holding`، `bag_detected` |
| `people.csv` | سطر لكل شخص: أول وآخر ظهور (بالثانية)، المدة، النوع، الشنط، والحاجات اللي مسكها |
| `objects.csv` | كل نوع حاجة اتشاف: أكتر عدد في فريم واحد، وأول وآخر ظهور |

الملفات بتتفتح في Excel مباشرة، والعربي بيظهر فيها صح.

## مشاكل معروفة

- **سطور حمرا فيها `cublasLt64_13.dll ... missing`:** موديلات الوش اشتغلت على الـ CPU. شغّل `venv\Scripts\python check_gpu.py` واعمل الأمر اللي هيقولك عليه.
- **FPS قليل:** اتأكد إن اللابتوب في الشاحن، وإن البانل مكتوب فيها `Device: GPU`.
- **الكاميرا مش بتفتح:** جرّب `run.bat 1`.
- **حجم الشنطة تقريبي:** بيتحسب من نسبة طول الشنطة لطول الشخص، على أساس إن متوسط الطول 170 سم.
